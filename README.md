# Видеочат

Безопасное приложение для видеочата двух человек с защитой паролем, построенное на Node.js, Socket.IO и WebRTC.

## Возможности

- 🔒 **Защита паролем**: Только пользователи с правильным паролем могут войти в чат
- 👥 **Ограничение на двух человек**: Чат поддерживает ровно 2 пользователя
- 🎥 **Видеочат в реальном времени**: Высококачественная peer-to-peer видеосвязь
- 🎤 **Управление звуком**: Включение/выключение звука и видео во время разговора
- 📱 **Адаптивный дизайн**: Работает на компьютерах и мобильных устройствах
- 🔄 **Автоматическое переподключение**: Корректная обработка отключений пользователей

## Установка

1. Клонируйте или скачайте этот проект
2. Установите зависимости:
   ```bash
   npm install
   ```

## Настройка

1. Отредактируйте файл `.env` и установите желаемый пароль:
   ```
   CHAT_PASSWORD=ваш_секретный_пароль
   PORT=3000
   ```

## Использование

1. Запустите сервер:

   ```bash
   npm start
   ```

2. Откройте браузер и перейдите по адресу `http://localhost:3000`

3. Для начала видеочата:

   - Введите **пароль** (указанный в файле .env)
   - Нажмите "Войти в чат"

4. Поделитесь паролем с человеком, с которым хотите общаться

5. Когда оба пользователя войдут с правильным паролем, видеочат автоматически начнется

## Как это работает

### Система паролей

- Пароль задается в файле `.env` и является статичным для всех сессий
- Пользователи должны ввести правильный пароль для входа
- Неправильные пароли отклоняются с сообщением об ошибке

### Ограничения чата

- Чат может вместить ровно 2 пользователя
- Если третий пользователь попытается войти, он получит ошибку "Чат переполнен"

### Возможности видеочата

- **Переключение видео**: Включение/выключение камеры
- **Переключение звука**: Включение/выключение микрофона
- **Покинуть чат**: Выход из чата и возврат к экрану входа

### Технические детали

- **Backend**: Node.js с Express и Socket.IO для связи в реальном времени
- **Frontend**: Vanilla JavaScript с WebRTC для peer-to-peer видео
- **Сигналинг**: Socket.IO обрабатывает WebRTC сигналинг (предложения, ответы, ICE кандидаты)
- **STUN серверы**: Использует публичные STUN серверы Google для прохождения NAT

## Устранение неполадок

### Доступ к камере/микрофону

- Убедитесь, что браузер имеет разрешение на доступ к камере и микрофону
- Проверьте, не используют ли другие приложения вашу камеру
- Попробуйте обновить страницу, если доступ к медиа не удался

### Проблемы с подключением

- Убедитесь, что оба пользователя используют одинаковый пароль
- Убедитесь, что сервер запущен на порту 3000
- Для продакшена настройте правильные STUN/TURN серверы для лучшей связности

### Ошибка "Чат переполнен"

- Каждый чат поддерживает только 2 пользователей
- Если вы получили эту ошибку, подождите, пока кто-то не покинет чат

## Примечания по безопасности

- Пароль хранится только в памяти и не шифруется
- Для продакшена внедрите правильную аутентификацию и HTTPS
- Рассмотрите добавление ограничения скорости и валидации ввода
- WebRTC обеспечивает сквозное шифрование для видео/аудио потоков
